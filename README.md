# A/B Testing Framework with Statistical Rigor

## Overview

This project implements a complete A/B Testing Framework for evaluating an E-Commerce Checkout Page Optimization experiment using statistical and Bayesian analysis.

The notebook demonstrates:

* Frequentist hypothesis testing
* Bayesian A/B analysis
* Statistical power analysis
* Effect size calculation
* Revenue impact analysis
* Business recommendation reporting
* Advanced data visualization

---

# Project Features

## Statistical Analysis

* Chi-Square Test
* Z-Test for proportions
* T-Test on revenue
* Confidence Intervals
* Cohen’s h Effect Size
* Statistical Power Analysis

## Bayesian Analysis

* Beta posterior distributions
* Monte Carlo simulation
* Probability of treatment outperforming control
* Bayesian credible intervals

## Visualizations

* Conversion rate comparison
* Posterior lift distribution
* Revenue distribution
* Statistical significance plots
* Funnel comparison
* Power analysis curve
* Executive scorecard

# Installation

Clone the repository:

```bash
git clone https://github.com/your-username/ab-testing-framework.git
```

Move into the project directory:

```bash
cd ab-testing-framework
```

Install dependencies:

```bash
pip install -r requirements.txt
```
